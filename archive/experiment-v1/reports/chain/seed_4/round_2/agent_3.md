# Critical Analysis: Vertex Model Claims Lack Mathematical Rigor

## THE FUNDAMENTAL FLAW: MISAPPLYING INTEGRABILITY

The vertex model report commits a **category error** by forcing integrable system machinery onto inherently non-integrable combinatorics. As a Purbhoo bijection specialist, I must challenge several core claims:

**The "free-fermion" characterization of LR tableaux is problematic.** While Schur functions have fermionic representations via the boson-fermion correspondence, **LR tableau combinatorics itself is not naturally free-fermionic**. The report conflates:
- Algebraic properties of symmetric functions
- Combinatorial rules for tableau construction
- Statistical mechanical interpretations

These are **distinct mathematical objects** that don't automatically transfer structure between levels.

## MIGRATION ≠ INTEGRABILITY REDUCTION

The most serious error is interpreting Purbhoo's migration as "fermion interaction removal." **Migration is purely combinatorial jeu de taquin**, operating on:
- Discrete rhombi positions in mosaics
- Local hexagonal flip rules
- Path-dependent tableau reading orders

The report provides **zero evidence** that these discrete moves preserve any continuous integrable structure. The Yang-Baxter equation governs **continuous parameter families** of R-matrices, not discrete combinatorial bijections.

## SPECTRAL PARAMETERS DON'T EXIST HERE

The claim about "spectral parameter deformations connecting KTW and LR" is **mathematically meaningless** in this context. KTW puzzles are:
- Discrete triangular tilings with fixed boundary conditions
- Governed by local rhombus constraints (not spectral equations)
- Counted by **finite sums**, not partition functions with continuous parameters

Where exactly are these alleged "spectral parameters" supposed to appear in puzzle piece assignments?

## THE YANG-BAXTER RED HERRING

**There are no eigenvalues involved.** The report mistakes discrete counting problems for continuous spectral analysis.

## CHALLENGING THE VERTEX WEIGHT CONFUSION

## THE QUANTUM DEFORMATION MISDIRECTION
