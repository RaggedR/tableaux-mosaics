# Critical Analysis: Vertex Model Claims Require Immediate Verification

**THE SPECTRAL PARAMETER INVOCATION IS UNSUBSTANTIATED**

As a Purbhoo bijection specialist, I must challenge the fundamental premise: **where is the evidence that KTW puzzles naturally carry spectral parameters?** The vertex model framework is being imposed without justification.

In Purbhoo's construction, puzzle → mosaic → migration → LR-tableau, each step is **deterministic and combinatorial**. The migration algorithm consists of explicit local hexagonal flips that move colored rhombi through the mosaic. These are discrete moves, not parametrized by continuous λ-values. The Yang-Baxter enthusiast has not demonstrated how puzzle boundary conditions (ν,μ,λ̂) naturally acquire spectral parameters.

**MIGRATION IS JEU DE TAQUIN, NOT TRANSFER MATRIX EVOLUTION**

The core issue is being missed: migration is fundamentally a **jeu de taquin sliding process**. In Purbhoo's framework:

1. Each hexagonal flip in the mosaic corresponds to a jdt slide in the skew tableau
2. The **reading order** of tableau entries directly corresponds to an order on puzzle tiles
3. Schutzenberger involution acts naturally on both sides of the bijection

The vertex model advocate has not explained how R-matrix evolution could replicate **jeu de taquin rectification**. These are completely different dynamical systems: jdt preserves tableau shape through local sliding rules, while transfer matrices evolve quantum states.

**THE FREE-FERMION CLAIM LACKS PUZZLE-SPECIFIC EVIDENCE**

The assertion that "KTW puzzles might be free-fermionic" is speculative. Free-fermion vertex models have very specific correlation functions and satisfy R(λ) = λI + P. But:

- KTW puzzles have **three types of rhombi** (horizontal, NE-SW, NW-SE)
- Each rhombus carries **specific constraints** from adjacent puzzle pieces
- The **nabla choices** create local dependencies that don't obviously factor

The burden is on the vertex model advocate to prove that puzzle rhombi weights satisfy free-fermion constraints, not merely assert it's possible.

**BOUNDARY PROPAGATION IN PUZZLES IS GEOMETRICALLY CONSTRAINED**

The Yang-Baxter framework assumes K±(λ) boundary matrices, but KTW puzzles have **rigid geometric constraints**:

- Boundary conditions fix **specific edge labels** (not parametrized families)
- Internal consistency requires **exact rhombus matching** at vertices
- The **triangular lattice geometry** imposes non-negotiable local rules

How do reflection equations [K-, R] handle the fact that puzzle boundaries are **fixed combinatorial data**, not adjustable parameters? The geometric rigidity of puzzles doesn't naturally accommodate the flexibility that integrable boundaries typically require.

**THE DOMAIN WALL CONNECTION IS INTRIGUING BUT UNPROVEN**

The DWBC suggestion is the most concrete claim, but remains unestablished. If KTW puzzles correspond to domain wall six-vertex configurations, we need:

1. **Explicit vertex weight assignment** for each rhombus type
2. **Verification** that these weights satisfy Yang-Baxter relations
3. **Proof** that the resulting partition function counts LR coefficients

The Izergin-Korepin determinant formula is beautiful, but invoking it without demonstrating the correspondence is premature.

**THE FUNDAMENTAL CHALLENGE: BIJECTION vs. GENERATING FUNCTION**

Here's the crucial distinction the vertex model advocate misses: Purbhoo's construction provides an **explicit bijection** between individual puzzles and individual LR-tableaux. Each puzzle corresponds to exactly one tableau through the migration algorithm.

Vertex models typically compute **generating functions** - weighted sums over configurations. Even if KTW puzzles correspond to some vertex model partition function, this doesn't immediately yield the **canonical bijection** that growth diagrams seek to provide.
